# 2pi-diagno
2π_Diagno: aplicativo web de diagnóstico de maturidade digital para empresas. Avalia Nuvem, ERP/CRM, IA e Segurança/LGPD em 8 perguntas, calcula o índice de 0 a 100%, exibe gráfico radar e gera um laudo de boas práticas. Feito com IA generativa, HTML, Tailwind e Chart.js, publicado no GitHub Pages.
